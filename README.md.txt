# Foundations of IoT – Laboratory Experiments

## About

This repository contains the laboratory experiments performed as part of the Foundations of IoT course.

The experiments are organised according to the hardware platform used, with separate folders for each experiment.

## Hardware Platforms

### 8051
Contains experiments implemented using the AT89S52 microcontroller and the Keil µVision development environment.

### STM32
Contains experiments implemented using STM32 development boards and the STM32 development environment.

## Documentation

Each experiment folder contains:
- Experiment details and task description.
- Hardware setup and platform information.
- Circuit diagram.
- Core logic and implementation details.
- Source code and project files.
- Inference and observations.

## Submission

This repository is maintained as part of the Foundations of IoT laboratory coursework.

All experiments are organised according to the prescribed laboratory submission guidelines.
